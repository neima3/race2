## Phase 7 — Ghost sharing (2026-09-12) ✅
Shipped:
- `src/game/share.ts` (new) — compact ghost codec, fully separate from the in-memory `serializeGhost` format. Envelope `#g=v1.<trackId>.<timeMs>.<code>` (human-parseable prefix, code last, base64url). Code payload: 1 flag byte (0 = raw quantized, 1 = RLE+deflate) + body. Body = 35-byte header (u16 sampleCount LE, u32 t0, u32 tSpan, 3×(f32 min + f32 scale) track-bbox from `def.points` padded 30m+5%) + 10 bytes/sample (u16 x/y/z fixed-point vs bbox, 3×8-bit smallest-three quaternion comps with dropped-largest canonicalized positive, u8 dropped-comp index). Sample planes byte-transposed before RLE+deflate (deflate alone only got ~17% on interleaved fixed-point; transposition got the 60s code from 10027 → 6512 chars). 30Hz recording downsampled to 15Hz (every 2nd sample); decode rebuilds times linearly from t0/tSpan (exact endpoints). Async via `CompressionStream('deflate')` when available, raw-quantized fallback otherwise; flag byte makes decode environment-independent. Orientation sanity on decode: sum-of-squares ≤ 1.05, dropped comp reconstructed ≥ 0, rotation-matrix det > 0.5 — any violated sample rejects the whole batch (ShareError → empty ghost + toast, never a crash). 90s cap enforced at encode (trim), decode (tSpan check) and post-decode filter.
- `src/game/race.ts` — `GhostSample` now exported; `RaceController.useExternalGhost(samples | null)` loads a friend ghost in place of the save/dev ghost (normal path byte-identical; `serializeGhost`/`deserializeGhost` untouched).
- `src/core/save.ts` — additive `friendGhosts: { [trackId]: {code, timeMs, dateMs} }` on the versioned AllSaves store (schemaVersion stays 2 — career gate pins it), sanitizer drops corrupt entries, API `friendGhost(id)`/`setFriendGhost(id, entry)` (newest wins, persisted via existing `persistSaves`).
